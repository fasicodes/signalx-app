## 3. What is live (engine 5)

Only streams whose model passed **one test on data it never saw** run (`streams.passed_test`: ≥ 50 signals,
≥ +0.05R per signal after costs, profit factor ≥ 1.1, drawdown ≤ half the total). Test period 2025-10-01 → 2026-11-08,
94 coins, costs 0.30 % round trip + funding for longs, entry one minute after the candle close.

| Stream | Live? | How it works | Plan | Unseen-data result |
|---|---|---|---|---|
| Crypto 4h | **ON** | `signal_engine.py` + `signal_model.json` (trees of engine 3.1). Strong = top 3 % score; if no signal for 24 h the best coin gets a "standard" one; max 5 new per candle | stop 2×ATR(4h); targets 0.5R / 1R / 2R, ⅓ each, stop → entry after TP1, → TP1 after TP2; 54 candles (9 days) | 852 signals (2.1/day), **75.5 %** reach TP1, +0.12R/signal, PF 1.48, DD −14R |
| Crypto 1h | **ON** | `models/crypto_1h.json`: the engine-5 **4-hour model read every hour** on the 4h candle ending at that hour (4 shifted grids). Top 2 % score, max 3 per hourly candle, cooldown 4 | stop 2×ATR(4h); one target 0.5R (whole position); 216 hourly candles | 781 signals (1.9/day, **in bursts**, ~1 day in 8), **82.5 %** reach target, +0.19R/signal, PF 2.03, DD −32R |
| Crypto 15m | off | model passed validation, failed unseen test | – | 69.4 %, +0.01R |
| Forex / gold 15m, 1h, 4h | off | no setting reached the validation target (best ≈ 70 %, +0.03R) | – | unseen years never opened |

Notes to remember:
- "Win" = first target at half the stop distance; a random entry hits it ~2 times in 3, and one full loss = two
  first-target wins. The average R after costs is the real measure.
- 4h with the old single 1R target (engine 3.2): 59.4 % win, +0.19R – engine 5 trades some profit for fewer stops.
- Live engine was checked against the research: **1,190 / 1,190** signals identical (`research/v5/live_check.py`).
- A daily "filler" signal for the 1h stream was tested and lost money → not used.

## 5. How to re-run things

```bash
pip install -r requirements.txt numba pyarrow
for t in tests/test_*.py; do python "$t" || echo "FAILED: $t"; done      # all pass on the branch
```
Research (needs ~1 GB of data, downloaded from public GitHub repos; data is NOT in the repo):
```bash
export V5_DIR=/some/work/dir
python research/v5/fetch.py fx_a && python research/v5/fetch.py fx_b && python research/v5/fetch.py crypto
python research/v5/lab5.py build crypto_4h && V5_KEEP_FOLDS=1 python research/v5/lab5.py wf crypto_4h
python research/v5/lab5.py tune crypto_4h && python research/v5/lab5.py decide crypto_4h
python research/v5/rolling.py build && python research/v5/rolling.py val   # holdout: rolling.py final (already run once)
python research/v5/summary.py
```
Rule: the holdout period may be scored **once** per chosen setting; never tune on it.
