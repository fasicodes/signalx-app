Binance connect karein
Keys yahan banayein: demo.binance.com → profile → API Management. Market (Spot/Futures) wahi use hoga jo Bot settings mein chuna hai.
Live key banate waqt sirf Enable Reading aur Spot/Futures Trading ON rakhein. Withdrawals hamesha OFF — withdrawal wali key server qabool nahi karega. Behtar hai IP whitelist bhi lagayein.
Keys server par encrypted save hoti hain aur browser mein kabhi store nahi hotin. Secret dobara kabhi dikhaya nahi jayega.
